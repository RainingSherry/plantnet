其中 `RG` 表示 **Reliability-Gated**。之所以新建目录，是为了避免污染当前 `NeighborMix_scMAE`。当前版本本质上仍保留 scMAE AutoEncoder，只在训练时加入一个保守 pseudo branch；README 也明确说明它是 anchor-recovery mixed view，且 `mix_weight`、`consistency_weight`、`target_mode` 只是兼容旧 CLI，并未真正使用。 当前代码中的邻居图来自 PCA + L2 normalization + cosine KNN，pseudo cell 是固定 `alpha` 的邻居表达凸组合。  训练时 pseudo branch 的目标仍是原始 anchor cell `x`。

# BDD：Reliability-Gated NeighborMix-scMAE

## 0. 目标

当前 fixed NeighborMix 的问题不是完全无效，而是**数据结构依赖强**：有些数据集提升，有些数据集明显下降。新版本目标不是盲目增加混合，而是让模型学会：

```text
谁可以混？
和谁混？
混多少？
什么时候少混甚至不混？
```

因此改良版应从：

```math
x_i'=\alpha x_i+(1-\alpha)\operatorname{neighbor\_mean}_i
```

改成：

```math
x_i'=(1-g_i)x_i+g_i\sum_{j\in\mathcal{N}(i)}a_{ij}x_j
```

其中：

```text
a_ij：边级邻居权重，决定“和谁混”；
g_i：节点级门控，决定“整体混多少”。
```

训练时不能用真实标签筛邻居，所有 gate 和 reliability 必须来自无监督结构信号。

# 2. 方法原理

## 2.1 训练邻域图

```math
\rightarrow \ell_2\operatorname{-normalize}
\rightarrow \operatorname{cosine\ KNN}
```

但新版本必须保存训练时真实邻域，而不是只在外部分析脚本中重新计算 KNN。

```text

```

## 2.2 边级可靠性 Edge Reliability

边级可靠性回答：

```text
邻居 j 对当前细胞 i 是否可靠？
```

推荐初版使用可解释的 analytic reliability，不直接上 attention：

```math
r_{ij}
=
\exp(\gamma_s\operatorname{sim}_{ij})
\cdot
(1+\gamma_m\operatorname{Mutual}_{ij})
\cdot
(1+\gamma_{snn}\operatorname{SNN}_{ij})
\cdot
\exp(-\gamma_d d_{ij})
```

其中：

```math
\operatorname{Mutual}_{ij}=1
\quad\text{if}\quad
j\in\mathcal{N}(i)\ \text{and}\ i\in\mathcal{N}(j)
```

```math
\operatorname{SNN}_{ij}
=
\frac{
|\mathcal{N}(i)\cap\mathcal{N}(j)|
}{
|\mathcal{N}(i)\cup\mathcal{N}(j)|
}
```

邻居最终融合权重：

```math
a_{ij}
=
\frac{
p_{ij}r_{ij}
}{
\sum_{l\in\mathcal{N}(i)}p_{il}r_{il}+\epsilon
}
```

其中 `p_ij` 是当前 KNN softmax probability。

### Stability rule: edge weights must not collapse

由于 `r_ij` 使用指数项和乘法项，第一版必须保存并检查权重是否过尖锐。

必须记录：

```text
edge_weight_entropy
effective_neighbor_count
max_edge_weight_mean
max_edge_weight_p95
fraction_effective_neighbors_lt_2
```

验收要求：

```text
edge_weight_entropy 不应长期接近 0
effective_neighbor_count 不应在大多数细胞上接近 1
max_edge_weight_p95 不应持续接近 1
```

若发生 collapse，必须启用至少一种稳定措施：

```text
temperature normalization
log-space normalization
reliability clipping
max_edge_weight clipping
fallback to mutual mode
```

---

## 2.3 节点级门控 Node Gate

节点门控回答：

```text
当前细胞 i 整体应该混多少？
```

推荐公式：

```math
g_i
=
g_{max}
\cdot
\sigma
\left(
\beta_0
+
\beta_1\operatorname{MutualRatio}_i
+
\beta_2\operatorname{SNNAvg}_i
-
\beta_3\operatorname{PerturbNorm}_i
-
\beta_4\operatorname{Uncertainty}_i
\right)
```

其中：

```math
\operatorname{MutualRatio}_i
=
\frac{
|\{j\in\mathcal{N}(i): i\in\mathcal{N}(j)\}|
}{
|\mathcal{N}(i)|
}
```

```math
\operatorname{SNNAvg}_i
=
\frac{1}{|\mathcal{N}(i)|}
\sum_{j\in\mathcal{N}(i)}
\operatorname{SNN}_{ij}
```

```math
\operatorname{PerturbNorm}_i
=
\frac{
\|m_i-x_i\|_2
}{
\|x_i\|_2+\epsilon
}
```

`Uncertainty_i` 必须是无监督量，允许来源包括：

```text
reconstruction uncertainty
neighbor probability entropy
dropout stochastic embedding variance
pseudo perturbation instability
local density uncertainty
```

禁止来源包括：

```text
true labels
cluster-vs-label purity
label-aware marker genes
ground-truth cell type entropy
oracle clustering metrics
```

若第一版尚未实现稳定的 `Uncertainty_i`，必须设为 0 并在 `gate_summary.json` 中记录：

```json
{
  "uncertainty_enabled": false,
  "uncertainty_source": "disabled"
}
```

初始默认：

```text
gate_max = 0.15
```

原因：当前 fixed NeighborMix 的 `alpha=0.9` 等价于只注入 10% 邻居信息，因此第一版 gate 不应过强。

---

## 2.4 Gated pseudo-cell

先聚合邻居：

```math
m_i
=
\sum_{j\in\mathcal{N}(i)}
a_{ij}x_j
```

再构造 pseudo-cell：

```math
x_i'
=
(1-g_i)x_i
+
g_i m_i
```

pseudo branch 仍保持 anchor recovery：

```math
\mathcal{L}_{pseudo,i}
=
\mathcal{L}_{scMAE}
(
\operatorname{Mask}(x_i'), x_i
)
```

总损失：

```math
\mathcal{L}
=
\mathcal{L}_{real}
+
\lambda
\frac{1}{B}
\sum_{i\in B}
\bar g_i
\mathcal{L}_{pseudo,i}
+
\eta\mathcal{L}_{gate}
```

其中：

```math
\bar g_i
=
\operatorname{clip}
\left(
\frac{g_i}{g_{max}+\epsilon},
0,
1
\right)
```

第一版可以设：

```text
eta = 0
```

只记录 gate 分布。若发现 gate 全部接近 0 或全部接近 `gate_max`，再加入 gate regularization。

# 3. 必须支持的 mix mode

```gherkin
Feature: Multiple mix modes for mechanism validation

  Scenario: User selects mix_mode
    Given a dataset and a configured RGNeighborMix run
    When the user passes --mix_mode
    Then the phase-1 run script must support none, fixed, mutual, reliability, random, and far
    And attention must be reserved for phase 2
```

| mix_mode      | 含义                           | 用途           |
| ------------- | ---------------------------- | ------------ |
| `none`        | 不启用 pseudo branch            | scMAE 等价对照   |
| `fixed`       | 复现当前 fixed NeighborMix       | sanity check |
| `mutual`      | 只混 mutual KNN 邻居             | 检验坏邻居过滤是否有效  |
| `reliability` | edge reliability + node gate | 主方法          |
| `random`      | 随机混合非邻居                      | 负对照          |
| `far`         | 混合远邻                         | 负对照          |
| `attention`   | 预留 KNN-restricted attention  | 第二阶段，不进入第一轮正式比较 |

### Scenario: attention 不得提前混入主实验

**When** `--mix_mode attention` 在 Phase 0 或 Phase 1 被调用

**Then** 程序必须清晰报错或要求显式开启第二阶段开关。
**And** `attention` 结果不得写入 `rg_nm_v1_reliability` 的输出目录。
**And** `attention` 不得参与 `none/fixed/mutual/reliability/random/far` 的第一轮总表。

```gherkin
Feature: Edge reliability

  Scenario: Suppress unreliable neighbors
    Given anchor cell i has KNN neighbors
    When mix_mode is reliability

    And non-mutual neighbors should receive lower reliability
    And low-SNN neighbors should receive lower reliability
```

```gherkin
Feature: Node gate

  Scenario: Adaptively control total neighbor injection
    Given anchor cell i has neighbor aggregate m_i
    When gate_mode is topology
    Then g_i must be between gate_min and gate_max
    And high-reliability cells should receive larger g_i
    And high-perturbation cells should receive smaller g_i
    And x_prime must equal (1-g_i)*x_i + g_i*m_i
```

```gherkin
Feature: Gate-weighted pseudo loss

  Scenario: Down-weight unreliable pseudo branches
    Given each batch has node gates g_i

    And real scMAE loss must always remain active
    And batches with low gate values should contribute less pseudo regularization
```

# 10. 成功标准

改良版不要求每个数据集都赢，但必须满足：

```text
1. 相比 fixed NeighborMix，negative 数据集平均 ARI 损害减少；
2. 相比 scMAE，全量平均 ΔARI 不应明显为负；
3. worst-case ARI drop 小于 fixed NeighborMix；
4. positive 数据集上保留 fixed NeighborMix 的大部分收益；
5. rare-cell recall 不应比 scMAE 明显下降；
6. embedding between/within ratio 不应在 negative 数据集继续明显塌缩。
```

如果出现以下情况，应暂停扩大实验：

```text
node_gate.npy 全部接近 0：gate collapse；
node_gate.npy 全部接近 gate_max：退化成 fixed mixing；
RandomMix 和 reliability 一样好：邻域可靠性假设不成立；
FarMix 也提升：当前理论解释需要重写；
negative 数据集 rare recall 继续下降：稀有细胞保护不足。
```

# 11. 什么时候进入 Attention 版本？

不要一开始就做 attention。

只有当 reliability-gated 版本满足以下条件后再进入：

```text
1. 明显减少 fixed NeighborMix 的 negative damage；
2. gate diagnostics 能解释哪些细胞少混、哪些细胞多混；
3. RandomMix / FarMix 证明局部可靠邻域确实必要；
4. per-cell-type 结果没有显示明显稀有类损害。
```

Attention 版本可以作为：

```text
--mix_mode attention
```

保留在同一目录中。

公式：

```math
s_{ij}
=
\frac{
(W_Qh_i)^\top(W_Kh_j)
}{
\sqrt{d_k}
}
+
\log(e_{ij}+\epsilon)
```

```math
a_{ij}
=
\operatorname{softmax}_{j\in\mathcal{N}(i)}(s_{ij})
```

注意：必须是 KNN-restricted attention，不做全局 self-attention。

# 13. 推荐论文叙事

不要写：

```text
NeighborMix universally improves scMAE.
```

应该写：

```text
Fixed neighbor mixing in masked autoencoding is data-structure dependent.
It can act as local denoising when neighborhoods are reliable, but may cause
boundary compression or rare-cell damage when neighborhoods are unreliable.
We therefore introduce a label-free reliability-gated NeighborMix module that
adaptively decides with whom and how much each cell should mix.
```

中文表述：

```text
固定邻域混合不是普适增强，而是一种依赖数据结构的局部扰动正则。
当邻域可靠时，它可能帮助去噪；当邻域跨越真实边界或稀有细胞被大类包围时，
它可能造成过度平滑和负迁移。因此，我们提出无标签可靠性门控的 NeighborMix，
在训练中自适应决定“和谁混”以及“混多少”。
```

这份 BDD 的核心是：**先用可靠性门控解决 fixed NeighborMix 的负迁移，再考虑 attention。** 这样比直接堆复杂注意力更稳，也更符合你当前实验结果。
