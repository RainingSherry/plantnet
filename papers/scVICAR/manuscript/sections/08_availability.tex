\section{Data and Code Availability}
\label{sec:availability}

All datasets analyzed in this study were obtained from the public sources and
accessions cited in \cref{sec:experiments}.  To respect source-specific
redistribution terms, the processed H5AD files used for confirmation are not
redistributed with the manuscript.  Instead, the reproducibility package
records source identifiers, preprocessing and filtering rules, dimensions, and
SHA-256 digests needed to reconstruct and verify each analytical input.

The double-anonymous review package contains the model, evaluation, aggregation,
statistical-analysis, and figure-generation code together with frozen
configuration manifests.  Each reported result is linked to a unique run
identifier, configuration hash, code-freeze identifier, and file-level checksum.
An archival public release of the reproducibility package will accompany the
final version of the article; no repository URL is asserted before that archive
has been deposited.
