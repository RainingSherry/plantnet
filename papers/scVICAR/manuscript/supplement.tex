\section{Purpose and Evidence Boundary}

This supplement records the complete protocol, model-development boundary, and
reproducibility checks.  NeighborMix-scMAE and RG-NeighborMix-scMAE were
developed through broad experiments on 16 datasets. Those runs motivated the
fixed and topology-adaptive formulations and are analyzed as development
evidence. The six frozen datasets in the main paper provide the confirmatory
analysis. The invalid \texttt{hrvatin\_geo} label variant is excluded because
it overlaps with \texttt{hrvatin} and has unsuitable label semantics.

After excluding the invalid \texttt{hrvatin\_geo} label variant, the development
table retained 15 datasets, three seeds, and 45/45 successful non-fallback runs
per ranked configuration. scVICAR-T (RG-NeighborMix-scMAE) achieved mean ARI
0.7955, compared with 0.7868 for scVICAR-F (NeighborMix-scMAE) and 0.7570 for
scMAE. The scVICAR-T difference from scMAE was 0.0385 in absolute ARI, or
5.08\% relative to the scMAE mean. The final F and T parameter signatures were selected using the same
development archive. These values describe development-stage competitiveness.
The confirmatory study was frozen before inspecting its scVICAR outputs and
provides the generalization estimate.

All variants use 1,000 selected genes, a 128-dimensional embedding, 80 epochs,
batch size 256, Adam with learning rate $10^{-3}$, mask ratio 0.4, $k=5$, four
sampled neighbors, temperature 0.2, and maximum coefficient 0.1. When
Seurat-style HVG selection returns fewer than 1,000 genes, deterministic
empirical variance supplies the frozen fallback. The run requires exactly the
requested number of genes.

External baselines are separately frozen across six interpreters/environments.
PCA, original scMAE, and scVI use $K$ during post-hoc clustering. scDCC,
scDeepCluster, and scRCL require $K$
in their published clustering-oriented architecture and are therefore labeled
known-$K$ training baselines.  Their per-cell labels are withheld from gradient
updates and checkpoint selection.  Every baseline emits cell identifiers; any
row-order or cell-set mismatch with the canonical H5AD is a hard failure.

During baseline execution, the initial scDeepCluster adapter was found to pass
Z-scored values as a ZINB count target when a legacy Scanpy HVG call retained
all 61,497 genes, producing non-finite loss. Aggregation excluded these runs.
The separately frozen \texttt{scdeepcluster\_repair\_v2} aligns non-negative raw
counts to the selected genes, derives size factors from raw library sizes, and
enforces the prespecified 2,000-gene input with a deterministic variance
fallback.  The architecture, training epochs, seeds, and known-$K$ contract are
otherwise unchanged.  Repaired runs must match their full interpreter,
package, parameter, and source identity hash; the other baselines remain bound
to the original baseline freeze.

\section{Downstream Leakage Controls}

For every split, reference and evaluation indices are archived and verified to
form a disjoint complete partition.  Reference labels are used to derive
reference markers. Evaluation labels are opened after cluster differential
expression and marker-overlap assignment for final scoring. The linear-probe
scaler and classifier are fitted in a
single pipeline on the labeled training subset; the remaining cells are
transformed only after fitting.  Every model seed and all five split seeds are
retained.

\section{Statistical Analysis}

The independent unit is the dataset.  Downstream split replicates are averaged
within run, then model seeds within dataset.  Planned contrasts are scVICAR-F
versus NoMix, scVICAR-T versus NoMix, and scVICAR-T versus scVICAR-F.  We report
paired mean and median effects, win/tie/loss counts, a 10,000-replicate
hierarchical bootstrap interval, and a paired sign-flip permutation test.
Holm adjustment is applied across the three contrasts separately for each
endpoint. The dataset is the independent unit; cells, seeds, and splits are
nested computational observations.

\section{Traceability and Failure Recovery}

The canonical run identifier is
\begin{quote}
\texttt{dataset--variant--seed--config\_hash}.
\end{quote}
The configuration hash covers the resolved protocol, dataset digest, wrapper,
base model, graph, mixing, diagnostic, preprocessing and shared-utility source
files, together with the fixed Python binary and key package versions.  Each
remote directory contains a file-level checksum manifest and a
completion marker.  Uploads are verified in a partial directory and atomically
promoted.  Failed runs retain their local staging directory and are never
included by the aggregate collector.  The scheduler stops before local free
space falls below 5 GiB.

\section{Negative or Null Results}

All 108 confirmatory and 108 downstream run identifiers passed completeness
and checksum checks before aggregation. scVICAR-F changed mean confirmatory
ARI by $-0.002$ relative to NoMix, and scVICAR-T changed it by $+0.005$ with a
3/0/3 dataset split. Under complete edge replacement, ARI degradation favored
scVICAR-T on two datasets and scVICAR-F on one. Low-label probe changes were
small, with Holm-adjusted $p$-values above 0.05. Marker recovery and
marker-overlap annotation were heterogeneous and had negative mean changes for
scVICAR-T. The main text reports each result at its observed scale.
