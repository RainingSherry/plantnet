## 0. 一句话贡献声明（诚实版）

> We diagnose a concrete failure mode of Deep Embedded Clustering (DEC) on scRNA-seq data — per-dimension variance collapse of the clustering latent — and show that a single VICReg-style per-dimension variance-floor term repairs it inside an scMAE+DEC backbone (ARI +0.272 over DEC, 17/18 datasets; effective dimensionality 60→114; 2.5× lower seed variance), while a re-evaluation under macro-F1 and rare-cluster recall reveals that ARI systematically over-credits such sharpening methods and that rare-cell discovery remains an open problem no method — including ours — solves.

要点：
- 贡献是**诊断 + 机制性修复(对 DEC)** ⊕ **评测重估(揭示 ARI 高估锐化 + 稀有细胞空档)**，两条腿都诚实、可证。
- 不主张"新 SOTA 精度方法"。主张"稳健全覆盖骨干 + 机制解释 + 评测纠偏"。

## 1. 逐节写作蓝图

### Abstract（对照 scMAE.md 的 Motivation/Results 结构）
- Motivation: scRNA-seq 聚类是细胞类型鉴定与稀有细胞发现的基础；深度嵌入聚类(DEC 系)把聚类目标耦合进表示学习，但在综合 benchmark 中表现垫底（呼应 scCluBench "表示与聚类解耦/DEC 弱基线"）。
- Method(诚实): 以 zero-masking 的 scMAE 为骨干、DEC 为耦合聚类头，诊断出**每维方差坍缩**，引入**每维 std-floor**(VICReg 方差项)修复之。
- Results(必须给的数字): vs DEC ARI +0.272(17/18)、NMI +0.238(18/18)、eff-dim 60→114、种子方差降 2.5×；在 23 数据集全覆盖里稳健(平均 ARI 排名第 3)。**明确写:与基座 scMAE 精度相当而非超越**。
- 转折(诚实亮点): 换用 macro-F1 / 稀有簇 recall 重估，发现 ARI 系统性高估 DEC 类锐化方法，且稀有细胞发现无方法确立优势 → 提出这是开放问题。
- 禁止: "outperforms state-of-the-art"式措辞。

### 1 Introduction（循序渐进，从 benchmark 张力引出诊断）
分四段递进：
1. **背景**: scRNA-seq 聚类的价值；两个真实目标——常见类型鉴定 + 稀有细胞发现(引 scMAE.md 引言的 rare-cell 动机、scCluBench B1/B4)。
2. **方法谱系与张力**: 降维+传统聚类(PCA+KMeans/Seurat) vs 深度嵌入聚类(DCA/scDeepCluster/scVI/scMAE)。引 scCluBench 核心 finding：**多数方法把表示学习与聚类解耦，embedding 空间不利聚类**(B2)；DEC 作为耦合聚类头本应缓解解耦，却在 benchmark 里垫底(我方数据 DEC 平均排名 10.06，B3)。**这就是切入的疑问：耦合聚类的 DEC 为何反而垫底？**
3. **诊断即贡献**: 我们打开 DEC 发现**每维方差坍缩**(eff-dim 从 114 塌到 60)——KL 锐化把 latent 压到少数维度，KMeans 读出退化。引 scSSL-Bench：**VICReg 方差正则是通用 SSL 常胜机制**(A4)、**中大 embedding 维度一致更好**(A5) → std-floor 有顶会级血统，不是 ad-hoc。骨干选择理由：scSSL-Bench 证**随机 masking 优于邻域增广**(A2)，与我方 NeighborMix 净效应≈0(ARI Δ=−0.0014) 独立互证 → 用 zero-mask、弃邻域混合。
4. **贡献列表(诚实)**:
   - (i) 诊断 DEC 每维方差坍缩，量化 eff-dim 60→114 与 2.5× 稳定性；
   - (ii) 用单个 VICReg 方差项(std-floor)在 scMAE+DEC 骨干内修复之，vs DEC +0.272；
   - (iii) 评测重估：ARI 高估锐化(VarFloor macro-F1 排名从第 3 跌到第 6)、稀有簇 recall 上锐化类垫底、稀有细胞发现仍是开放问题；
   - (iv) 一个诚实强 baseline(PCA+KMeans known-K)与全覆盖对照，抬高结论可信度。
- **明确边界句**(放段末): "We do not claim to surpass the scMAE backbone in accuracy; our contribution is diagnostic and corrective with respect to DEC, and evaluative with respect to rare-cell discovery."

### 2 Materials and methods

#### 2.1 scMAE 骨干与 zero-masking 生成（公式 1–2）
- 描述输入矩阵 X ∈ R^{C×G}，编码器→mask 预测器→解码器三件套(照 scMAE.md 2.1.2)。
- **关键诚实改动**: 用 zero-mask（X_M = X⊙(1−M)）而非原 scMAE 的按基因 shuffle/swap。理由(写清): (a) 我方 conditional-shuffle 消融证在细粒度数据上全局 swap-noise 灾难性(Macosko 0.30 vs zero-mask 0.70)；(b) scSSL-Bench 证随机 masking 是最有效增广(A2)。
- 给公式 1(Bernoulli mask)、公式 2(zero-mask 施加)。

#### 2.2 掩码预测与加权重构（公式 3–6）
- mask 预测器 CE 损失(公式 3=scMAE 的 L_m)。
- 解码器 concat[E, 预测mask] → 加权 MSE 重构(公式 4=L_r，权重 Ω 公式 5)。
- scMAE 基础损失 L_scMAE=(1−γ)L_r+γL_m(公式 6)。
- 写"为何保留 mask→decoder 通路"：我方 decoder-bypass 消融证该通路是**稳定器**而非纯捷径(去掉后 Macosko 均值塌、方差爆)。

#### 2.3 DEC 耦合聚类模块（公式 7–8）
- student-t 软分配 q(公式 7)、target p 与 **confidence-gated KL + warmup**(公式 8)。
- 写"为何这么配"：沿用可复现的 rank13 设定(warmup 后才开 KL、按置信门控)，避免早期错误质心污染；这是"耦合表示与聚类"对 scCluBench 解耦难题(B2)的直接回应。
- 写"为何 DEC 需要修"：KL 锐化在压紧簇的同时把每维方差压塌(下一节诊断) → 引出 std-floor。

#### 2.4 诊断与 per-dim std-floor（公式 9–10）
- 先给**诊断量**：effective dimensionality（activity participation ratio）的定义与 DEC 上的观测(114→60)。这是把"坍缩"落成可测量的核心一步。
- 给 std-floor 损失(公式 9)：L_floor = (1/D)Σ_d relu(τ − σ_d)，σ_d 为 batch 内第 d 维标准差；这就是 VICReg 的方差项。
- 总目标(公式 10)：L = L_scMAE + λ_clu·L_KL + λ_floor·L_floor。
- **三条"为何这么用"必须写**：
  1. 为何是 relu(τ−σ_d) 每维方差地板：DEC 锐化致 eff-dim 塌到 60，地板逐维阻止坍缩、恢复到 114(是 VICReg 方差项，A4/A5 背书)。
  2. 为何作用在**整个聚类 latent**而非拆分子空间：latent-split 实测崩到 0.31——std-floor 的机制是"最大化活跃聚类维度"，拆分会直接夺走聚类容量、与该 lever 对冲。
  3. 为何不引入 X 派生的伪结构(基因程序/邻域图/marker)：program 消融证 real-NMF-program(0.458) 比 meaningless shuffle-target(0.632) 还差、都低于 baseline(0.779) → X 派生语义把 embedding 拽离细胞类型轴。这条支撑"只加方差地板、不加语义结构"的极简设计。

#### 2.5 数据集、对比方法、评测指标（照 scMAE.md 2.2–2.4）
- 数据集：23 数据集全覆盖(含 Macosko/Melanoma/Quake/Pollen/Tosches/Shekhar/worm_neuron 等)，标注含稀有类的数据集。
- 对比方法：scMAE、scMAE+NeighborMix、scDCC、scVI、Leiden、Louvain、SC3、DESC、scNAME、scziDesk、AttentionAE、scGPT，以及诚实强 baseline **PCA+KMeans(known-K)**。
- 指标(关键诚实设计)：主指标不只 ARI/NMI；**并列报告 macro-F1 与稀有簇 recall**(占比<2% 类)。写明理由：ARI/ACC 奖励大类(scCluBench B1)，掩盖稀有细胞目标 → 多指标才诚实。known-K 设定说明(K 取真值，非另一种算法)。

### 3 Results

#### 3.1 稳健全覆盖表现，并对 DEC 的修复（主结果）
- 主表：23 数据集 ARI(可选 NMI)，含 PCA+KMeans。**诚实陈述**：VarFloor 平均 ARI 排名第 3(4.13)、是跑满 23 集里排名最高者，远优于纯 DEC(10.06)与基座 scMAE(4.72)；但**只 4/23 夺冠、相对 scMAE 仅 8/18 更好(≈掷硬币)**，个别明显更差(Tosches 0.456 vs 0.606、worm 0.262 vs 0.482、Wang 0.729 vs 0.965)。
- **核心对比句**：vs DEC，ARI +0.272(17/18 胜)、NMI +0.238(18/18 胜)。这是本节的主张，不是"vs 一切"。
- 诚实附注：PCA+KMeans(known-K)强得离谱(平均排名 5.39、打赢 17 个里 12 个、Macosko 0.757>VarFloor)，说明经典 known-K 方法在细粒度上已很强，std-floor 的贡献应限定为"在 scMAE+DEC 深度骨干内修复方差坍缩"，不宣称超过一切。

#### 3.2 消融与机制（诊断证据链）
- **std-floor on/off**：去掉 std-floor 即回到 DEC 坍缩(消融管线 DEC+floor 0.70 vs DEC 无 floor 每个 resolution/head 都最差 0.15–0.35)。
- **eff-dim 恢复**：60→114 的曲线/柱状；配 between-class 方差谱。
- **稳定性**：种子方差比 DEC 小 2.5×(给标准差数字)。
- **latent-split 反向检验**：拆分子空间崩到 0.31 → 证明 std-floor 必须作用于完整 latent(机制自洽)。
- **head 不是天花板**(Phase-0)：冻结 embedding 重聚类，匹配 k 下 KMeans-known-K 是最好的 head(0.696 >> Leiden 0.276)，DEC-无-floor 在所有 resolution/head 都最差 → std-floor 的增益 head-无关，天花板在 embedding。
- **X 派生结构有害**(program 消融，锐利证据)：real-program(0.458) < shuffle-target(0.632) < baseline(0.779)，支撑极简方差地板设计。
- **NeighborMix 中性**：净 ARI Δ=−0.0014，与 scSSL-Bench "masking>邻域"(A2)互证 → 弃邻域混合。

#### 3.3 稀有细胞重估（诚实转折，诊断+空档）
- **指标切换重排**：把主指标从 ARI 换成 macro-F1，VarFloor 从第 3 跌到第 6、DEC 类跌到垫底(9.50) → **ARI 系统性高估锐化方法**(我方独有发现 C1)。
- **VarFloor vs scMAE 的锐化代价**：macro-F1 −0.073、仅 3/18 胜(Macosko −0.23 / worm −0.27 / Shekhar −0.18) → 量化"锐化以牺牲小类换大类"(C2)。**这里明确写 VarFloor 不如 scMAE，且原因是锐化。**
- **稀有簇 recall 排名(full run 重算，占比<2% 类)**：scDCC 0.507 > Leiden 0.481 > scMAE 0.473 > … > DEC 0.327 > scVI 0.186。**诚实陈述**：锐化类(VarFloor/DEC)在稀有簇垫底；scMAE 稀有簇也非最强；**没有任何方法在稀有簇上确立优势** → 呼应 scCluBench 承认稀有细胞注释难(B1/B4)，把它立为开放问题。
- 可复用 scCluBench 的 marker-overlap 注释协议(B5)做稀有簇的生物层校验，不必自建。

#### 3.4 数据集依赖与"无免费午餐"（诊断收束，替代生物 case study 或与之并列）
- 冠军散在多个方法(NeighborMix/VarFloor/Leiden/PCA/scDCC…)，不存在单一 SOTA。
- oracle portfolio 空间真实但小(Common-18 池 +0.073 显著)，而可兑现的 meta-selector(1-NN/ridge/tree × LODO)均不达标(最好仅捕获 +14% 且 CI 跨 0) → 根因是 benchmark 任务数太少(n≈18–23)，非方法错。
- 含义句：面对 No-Free-Lunch，价值不在"造更强/自适应聚类器"，而在**稳健全覆盖骨干 + 机制诊断 + 评测纠偏**。
- 若保留生物 case（照 scMAE.md 3.4）：可在一个数据集上用 eff-dim/方差谱可视化 + DEG/GO 说明 std-floor 保住的维度对应可解释的细胞类型轴（诚实：作为机制解释，不作精度主张）。

### 4 Discussion（对照 scMAE.md 讨论结构）
- 复述贡献：诊断 DEC 每维方差坍缩 + VICReg 方差地板修复(对 DEC) + 评测重估(揭示 ARI 高估锐化、稀有细胞空档)。
- std-floor 的血统与边界：是 VICReg 方差项(A4)，机制是保住有效维度(A5)；**只修 DEC，不使 scMAE 更准**。
- 锐化的双刃：压紧大类以牺牲小类，ARI 高估之；这是评测方法学贡献。
- 局限与失败的诚实记录(可正面写为"我们排除的路径")：PCA-init 移植/PCA⊕VF 融合/ARC 残差校正/meta-learning selector 均被证否(oracle 太小 或 信号抓不住 或 数据量不够) → 支撑"不存在可造出的更强自适应聚类器"的判断。
- 未来：面向稀有细胞的**反锐化**机制(而非 DEC 锐化)是被 scCluBench 点名(B4, e.g. CAKE)的正经方向。

## 3. 诚实边界清单

**能声称（数据支持）:**
- std-floor 修复 DEC 每维方差坍缩：vs DEC ARI +0.272(17/18)、NMI +0.238(18/18)、eff-dim 60→114、种子方差降 2.5×。
- VarFloor 是 23 数据集全覆盖里最稳健者(平均 ARI 排名第 3)，远优于纯 DEC。
- std-floor 增益 head-无关(Phase-0)、必须作用于完整 latent(latent-split 0.31 反证)。
- ARI 系统性高估 DEC 类锐化方法(换 macro-F1 从第 3 跌第 6)。
- 锐化以牺牲小类换大类(VarFloor vs scMAE macro-F1 −0.073, 3/18)。
- NeighborMix 净效应中性(ARI Δ=−0.0014)，与 scSSL-Bench masking>邻域互证。
- X 派生伪结构有害(program: real<shuffle<baseline)。
- 不存在单一 SOTA；可兑现的 meta-selector 达不到 oracle headroom(根因数据量)。

**不能声称（数据不支持，禁止写）:**
- ✗ VarFloor 精度超过 scMAE(实测 ARI −0.016、macro-F1 −0.073、仅 3/18 胜)。
- ✗ VarFloor 是新 SOTA / outperforms state-of-the-art。
- ✗ VarFloor 擅长稀有细胞(稀有簇 recall 上锐化类垫底)。
- ✗ 任何方法(含 scMAE、含我方)在稀有簇上确立了优势(scDCC 0.507 最高但未确立)。
- ✗ std-floor 超过一切(PCA+KMeans known-K 在 Macosko 0.757>VarFloor)。
- ✗ 邻域增广/基因程序/PCA 融合/ARC/meta-selector 带来提升(全部证否)。
- ✗ 跨消融管线与全 benchmark 管线直接比数字(预处理不同，须同管线内比较)。

## 5. 设计取向与主要取舍（中文简述）

**设计取向.** 我把论文重心从"提出更强聚类方法"改为"诊断 + 机制修复 + 评测纠偏"三位一体的诚实叙事，主线对手锁死为 DEC(+0.272、eff-dim 60→114、2.5× 稳定性)，而非 scMAE。全篇从两篇顶会 benchmark 的张力(scCluBench 解耦难题/DEC 垫底 + scSSL-Bench VICReg/masking 优势)循序推进：先问"耦合聚类的 DEC 为何垫底"，用可测量的每维方差坍缩作答，再用单个 VICReg 方差项修复，最后用 macro-F1/稀有簇 recall 把"ARI 高估锐化、稀有细胞仍是空档"立成评测方法学贡献。公式层面保留 scMAE 原 6 式骨架，只诚实改 zero-mask、加 DEC 门控 KL 与 std-floor，每式配来自探索或文献的"为何这么用"。

**主要取舍.** (1) 放弃"超越 scMAE/新 SOTA"的强主张——数据不支持，硬卖会被稀有簇 recall 与 macro-F1 当场证伪；改以"最稳全覆盖骨干"定位。(2) 主动写入 PCA+KMeans 强 baseline 与所有被证否的增强路径(PCA-init/融合/ARC/meta-selector)，短期看削弱"方法很强"的观感，长期换来结论可信度与一个更难被 reviewer 攻破的诊断论文。(3) 把稀有细胞从"卖点"降级为"开放问题"，与 scCluBench 的空档对齐，既诚实又给出未来方向(反锐化)。(4) 3.4 用 No-Free-Lunch/meta-selector 失败收束，明确价值不在造更强聚类器——这是与项目全史一致的诚实底线，也把潜在的"为何不做自适应选择"质疑提前挡掉。
