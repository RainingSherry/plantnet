scCluBench model-paper download package

This package was prepared from the model list in the uploaded scCluBench paper.

Contents:
- papers/: downloaded PDF papers
- manifest.csv: method-to-paper mapping, source URL, source type, page count, file size, and notes

Scope:
- User-requested methods were deduplicated.
- Louvain and Leiden are included as their original community-detection algorithm papers.
- One additional Seurat/Stuart et al. reference is included because the uploaded benchmark table cites Stuart et al. 2019 for Louvain and Leiden under the Seurat framework.

Access note:
- No paywall bypass was used.
- Where publisher PDFs were not accessible through public routes, public repository/preprint/author-hosted copies were used and noted in manifest.csv.
