# BDD v4.1: Feasibility Checkpoint for Reliability-Controlled Local Shrinkage

> 本 v4.1 块为**规范性修订**，覆盖后文 v4 中所有冲突内容。后文 v4 保留为设计背景与历史记录；实际实现、运行、验收和论文叙事以 v4.1 为准。

## 0. 审稿式判断

当前 RC-NM 只能作为 **feasibility checkpoint**，不能包装成成熟方法。

下一步不是扩展模块，而是把机制检验做得更干净、更可反驳。如果 `analytic_RC` 不能稳定赢过 `random_delta_matched`，或者 `edge_only / gate_only` 没有独立贡献，这条路线应及时降级或停止。

当前允许的主张只有：

```text
We evaluate whether reliability-controlled local shrinkage can reduce the negative transfer
of fixed NeighborMix in masked single-cell autoencoding.
```

中文表述：

```text
我们验证可靠性控制的局部收缩是否能减少 fixed NeighborMix 在单细胞 masked autoencoding 中的负迁移。
```

当前不允许的主张：

```text
RC-NM is SOTA.
RC-NM is top-tier ready.
RC-NM has been proven backbone-agnostic.
Reliability-controlled neighbor selection is already proven as the core mechanism.
Known-k KMeans proves fully unsupervised clustering ability.
```

### 0.1 对审稿意见的逐条判断

| 意见 | 判断 | v4.1 修改 |
| --- | --- | --- |
| 证据不支持顶会/顶刊主张 | 完全同意 | 明确写成 feasibility checkpoint，不写成熟方法 |
| `pseudo reconstruction-only` 不能不消融 | 同意，而且应前置 | 加入 Stage 1A `pseudo objective sentinel` |
| 数据集必须冻结 | 完全同意 | 冻结 Main-5，不根据 RC-NM 结果替换 |

| 方法 | 目的 | 公式 |
| --- | --- | --- |
| `fixed_control` | 旧 NeighborMix 控制组 | `(1-γ)x_i + γΣp_ijx_j` |


## 8. RC-NM 算子规范

### 8.1 self-loop smoothing operator

仍然使用：

```math
\tilde{X}=PX
```

其中：

```math
P_{ii}=1-g_i
```

```math
P_{ij}=g_i a_{ij},\quad j\in N(i)
```

```math
\sum_j P_{ij}=1
```

检查：

```text
P_ii = 1 - g_i
P_ij = g_i a_ij
row sum = 1
无有效边时 g_i = 0 或触发 fallback
pseudo-cell 无 NaN / inf
```

### 8.2 edge reliability 使用 soft mutual penalty

不要默认 hard mutual zero：

```math
M_{ij}=0 \quad \text{if non-mutual}
```

默认改为：

```math
M_{ij}
=
\begin{cases}
1, & \text{if mutual KNN}\\
m_{nonmutual}, & \text{otherwise}
\end{cases}
```

冻结：

```text
m_nonmutual = 0.25
```

edge reliability：

```math
r_{ij}
=
M_{ij}
\cdot
\exp\left(
-\frac{d_{ij}^2}{\tau_i\tau_j+\epsilon}
\right)
\cdot
SNN_{ij}^{\gamma}
```

### 8.3 edge veto with fallback

edge veto：

```math
e_{ij}=\mathbf{1}[r_{ij}>\delta_i]
```

其中：

```math
\delta_i = Q_{0.2}(\{r_{ik}:k\in N(i)\})
```

即只 veto 最低 20% 的边。

fallback：

```text
如果 valid neighbors < 3：
  保留 top-3 reliability neighbors。
```

除非所有边都是 NaN 或非法，否则不要让大量细胞直接 noMix。

必须记录：

```text
no_valid_neighbor_rate
fallback_rate
valid_edge_count_mean
```

### 8.4 benefit-risk gate 使用无标签分位数校准

不要手动调：

```text
alpha_s
beta_s
alpha_b
beta_b
```

定义：

```math
R_i = \operatorname{mean\_topk}(r_{ij})
```

```math
H_i = \sum_j a_{ij}\|u_i-u_j\|^2
```

其中 `u_i` 使用 PCA embedding，避免训练早期 latent 不稳定。

转成 rank score：

```math
\bar{R}_i = \operatorname{rankpercentile}(R_i)
```

```math
\bar{H}_i = \operatorname{rankpercentile}(H_i)
```

定义：

```math
S_i=\sigma(8(\bar{R}_i-0.5))
```

```math
B_i=\sigma(8(\bar{H}_i-0.75))
```

最终：

```math
g_i
=
g_{max}
\cdot
S_i
\cdot
(1-B_i)
```

## 9. random_delta_matched 负对照必须增强

只匹配：

```math
\|\tilde{x}_i-x_i\|
```

不够。必须至少匹配或检查：

```text
perturbation norm
library size / expression sum
zero fraction change
non-negativity
expression scale
```

推荐构造：

```text
1. 从相同 library-size decile 中采样随机细胞 x_r；
2. 计算 RC 扰动强度 Δ_i^RC = ||x_tilde_i^RC - x_i||；
3. eta_i = Δ_i^RC / (||x_r - x_i|| + epsilon)；
4. clip eta_i to [0, 1]；
5. x_tilde_i^rand = (1 - eta_i)x_i + eta_i x_r；
6. 保证 nonnegative、same preprocessing scale、no NaN / inf。
```

必须输出匹配质量：

```text
KS_distance_perturb_norm
median_library_size_diff
zero_fraction_diff
mean_expression_diff
clip_rate_eta
```

匹配质量阈值：

```text
KS_distance_perturb_norm <= 0.15
median_library_size_relative_diff <= 0.05
zero_fraction_absolute_diff <= 0.05
clip_rate_eta <= 0.20
```

若不满足，`random_delta_matched` 结果不能用于强结论。

## 11. 定量成功标准

### A 档：值得继续推进为主论文路线

同时满足大部分：

```text
1. analytic_RC vs fixed_control:
   mean ΔARI >= +0.015 across 5 dataset means
   或 across dataset-seed pairs mean ΔARI >= +0.015

2. negative transfer:
   analytic_RC 的 negative transfer count 少于 fixed_control
   negative transfer 定义为 ΔARI_vs_none <= -0.02

3. worst-case drop:
   analytic_RC 的最坏 ΔARI_vs_none 比 fixed_control 改善 >= 0.02

4. random control:
   analytic_RC > random_delta_matched 至少 4/5 datasets
   且 mean ΔARI_RC_minus_random >= +0.01

5. seeds:
   analytic_RC - fixed_control 的方向在至少 4/5 datasets 中跨 seed 一致
   或 10 个 dataset-seed pair 中至少 7 个为正

6. positive gains:
   在 positive datasets 上，analytic_RC 至少保留 fixed gain 的 50%
   或不比 fixed_control 低超过 0.02

7. rare / macro:
   macro-F1 和 rare-cell recall 不出现 >0.02 的平均下降

8. diagnostics:
   gate / edge / perturbation matching / graph TV 无严重失败。
```

A 档才值得进入 AE minimal transfer 和更完整 benchmark。

### B 档：可以继续修，但主张必须收窄

出现：

```text
analytic_RC 略好于 fixed_control，但 < +0.015；
random_delta_matched 接近 analytic_RC；
edge_only 或 gate_only 只有弱贡献；
部分 seed 方向不一致；
rare-cell recall 没明显坏，但也没改善。
```

允许主张：

```text
RC-NM is a promising perturbation-controlled regularizer,
but the reliability mechanism remains weak.
```

### C 档：停止作为主论文路线

任一情况出现：

```text
analytic_RC 不如 fixed_control；
analytic_RC ≈ random_delta_matched；
edge_only 和 gate_only 都无独立贡献；
gate collapse；
edge collapse；
random matching 不合格；
positive gains 大幅丢失；
rare-cell recall 明显下降；
graph TV 显示比 fixed 更强过平滑；
只有靠 attention / NB/ZINB 才能提升。
```

此时不要继续加模块。

# BDD v4：Feasibility Checkpoint for RC-NM

## 0. 当前 BDD 的边界

### 本轮目标

验证一个最小但论文级清晰的主张：

> fixed NeighborMix 可以被解释为统一强度的局部图平滑。
> 它在邻域可靠时可能去噪，在邻域不可靠时可能引入 neighbor bias。
> 因此，我们设计一个带自环的 reliability-controlled local shrinkage operator，用 edge reliability 决定和谁混，用 cell-level gate 决定混多少，并允许拒绝混合。

### 本轮不做

这一轮**不做**：

```text
full benchmark
full graph attention
GNN / Transformer
gene gate 训练
gene-adaptive mask 训练
NB/ZINB reconstruction
contrastive loss
cluster assignment head
foundation model adaptation
大量数据集大矩阵
```

这些都不是当前生死线。

### 本轮只回答 5 个问题

```text
Q1. RC-NM 是否比 fixed NeighborMix 更少负迁移？
Q2. edge reliability / edge veto 是否有独立贡献？
Q3. benefit-risk cell gate 是否有独立贡献？
Q4. random_delta_matched 是否能解释 RC-NM 的收益？
Q5. gate、edge weight、graph smoothing 是否没有 collapse 或明显过平滑？
```

如果这 5 个问题回答不了，后面加 attention、gene gate、NB/ZINB 都意义不大。

# 1. 方法身份：不要再写成 scMAE 小修补

## Feature 1：RC-NM 应被定义为 backbone-agnostic regularizer

### 背景

scMAE 可以作为第一个实现载体，但方法身份不应是：

```text
scMAE + NeighborMix + gate
```

而应是：

```text
Reliability-Controlled Local Shrinkage Regularizer
```

即：可靠性控制的局部收缩正则。

### 核心公式

把 pseudo-cell 生成写成带自环的图平滑算子：

```math
\tilde{X} = PX
```

其中：

```math
P_{ii}=1-g_i
```

```math
P_{ij}=g_i a_{ij}, \quad j\in N(i)
```

并且：

```math
\sum_{j\in \{i\}\cup N(i)}P_{ij}=1
```

解释：

```text
P：
  self-loop-preserving smoothing matrix，带自环的平滑矩阵。

P_ii：
  self-loop weight，自环权重，表示保留原细胞自己的比例。

a_ij：
  edge-level reliability weight，边级可靠性权重，决定和哪个邻居混。

g_i：
  cell-level shrinkage gate，细胞级收缩门控，决定混合强度。
```

### Scenario 1.1：方法命名

**Given** 当前方法从 fixed NeighborMix 改良而来

## Feature 3：edge reliability + edge veto

### 背景

fixed NeighborMix 默认 KNN 中的邻居都可以混，这在单细胞数据里不成立。

### 核心问题

```text
和谁混？
哪些边应该被拒绝？
```

### 推荐公式

先计算 raw edge reliability：

```math
r_{ij}
=
M_{ij}
\cdot
\exp\left(
-\frac{d_{ij}^2}{\tau_i\tau_j+\epsilon}
\right)
\cdot
SNN_{ij}^{\gamma}
```

其中：

```text
r_ij：
  raw edge reliability，未归一化边可靠性。

M_ij：
  mutual KNN indicator，互为近邻指示。
  如果 i 与 j 互为近邻，M_ij = 1，否则为 0 或较小值。

d_ij：
  distance，细胞 i 与 j 的距离。

τ_i, τ_j：
  local scale，局部尺度，用于避免不同密度区域距离不可比。

SNN_ij：
  shared nearest neighbor overlap，共享近邻重叠度。

γ：
  SNN strength，控制共享邻居信号的重要性。
```

加入 edge veto：

```math
e_{ij}=\mathbf{1}[r_{ij}>\delta_i]
```

归一化得到：

```math
a_{ij}
=
\frac{e_{ij}r_{ij}}
{\sum_{k\in N(i)}e_{ik}r_{ik}+\epsilon}
```

如果没有有效邻居：

```math
\sum_k e_{ik}=0
\Rightarrow
g_i=0
```

即：

```text
没有可靠邻居时，拒绝混合。
```

### Scenario 3.1：edge_only

**Given** fixed NeighborMix 使用原始 KNN 权重 `p_ij`
**When** 只替换成 reliability 权重 `a_ij`，但混合强度仍为固定 `γ`
**Then** 生成：

```math
\tilde{x}_i^{edge}
=
(1-\gamma)x_i
+
\gamma\sum_j a_{ij}x_j
```

### 这个实验代表什么

```text
edge_only 验证“坏邻居过滤是否有贡献”。
```

### 成功标准

```text
edge_only 在 negative datasets 上比 fixed 少负迁移；
edge_only 不显著损害 positive datasets；
no_valid_neighbor_rate 不过高；
effective_neighbor_count 不塌缩到 1。
```

### 失败解释

```text
edge_only ≈ fixed：
  当前 edge reliability 没抓住关键坏邻居。

edge_only < fixed：
  edge veto 可能过度保守，或 mutual/SNN/distance 定义错误。

大量 no_valid_neighbor：
  可靠边过滤太强，方法退化成 noMix。
```

## Feature 4：benefit-risk cell gate

### 背景

fixed NeighborMix 使用同一个全局混合强度 `γ`。
这意味着大类内部细胞、稀有细胞、边界细胞、连续状态细胞都被同样平滑，不合理。

### 核心问题

```text
哪些细胞应该混？
混多少？
是否应该拒绝混合？
```

### 推荐 gate 形式

不要只写：

```math
g_i=g_{max}\sigma(\alpha(R_i-\beta))
```

这只考虑了邻域可靠性，不考虑边界风险。

推荐改成 benefit-risk gate：

```math
g_i
=
g_{max}
\cdot
S_i
\cdot
(1-B_i)
```

其中：

```math
S_i=\sigma(\alpha_s(R_i-\beta_s))
```

```math
B_i=\sigma(\alpha_b(H_i-\beta_b))
```

解释：

```text
S_i：
  smoothing benefit，平滑收益估计。
  邻域可靠时较大。

B_i：
  boundary / bias risk，边界或偏差风险。
  局部异质性高时较大。

R_i：
  local reliability，局部可靠性。

H_i：
  local heterogeneity，局部异质性。
```

局部异质性可以定义为：

```math
H_i
=
\sum_{j\in N(i)}
a_{ij}
\|z_i-z_j\|^2
```

或先用 PCA 空间：

```math
H_i
=
\sum_{j\in N(i)}
a_{ij}
\|u_i-u_j\|^2
```

其中：

```text
z_i：
  encoder latent embedding。

u_i：
  PCA embedding。
```

如果不想在第一版引入 latent 动态，可以先用 PCA 空间。

### Scenario 4.1：gate_only

**Given** 邻居仍使用 fixed NeighborMix 的 `p_ij`
**When** 只把全局混合强度 `γ` 替换为细胞级 `g_i`
**Then** 生成：

```math
\tilde{x}_i^{gate}
=
(1-g_i)x_i
+
g_i\sum_j p_{ij}x_j
```

### 这个实验代表什么

```text
gate_only 验证“自适应混合强度是否有贡献”。
```

### 成功标准

```text
gate_only 比 fixed 更少负迁移；
gate 分布不是全 0 或全 g_max；
高异质性细胞的 gate 平均更低；
positive datasets 的收益不完全消失。
```

### 失败解释

```text
gate_only ≈ fixed：
  单独控制混合强度不够。

gate_only < fixed：
  benefit-risk gate 定义不合理，或过度保守。

g_i 全接近 0：
  退化为 noMix。

g_i 全接近 g_max：
  退化为 fixed-strength mixing。
```

## Feature 5：完整 RC-NM v1

### 核心方法

完整 Stage 1 主方法：

```math
\tilde{x}_i^{RC}
=
(1-g_i)x_i
+
g_i\sum_{j\in N(i)}a_{ij}x_j
```

或：

```math
\tilde{x}_i^{RC}
=
x_i
+
g_i\sum_{j\in N(i)}a_{ij}(x_j-x_i)
```

包含：

```text
edge reliability
edge veto
benefit-risk cell gate
self-loop-preserving smoothing
pseudo reconstruction-only
```

不包含：

```text
attention
gene gate
gene-adaptive mask
NB/ZINB
contrastive loss
GNN
Transformer
```

### Scenario 5.1：analytic_RC

**Given** 已实现 `a_ij` 和 `g_i`
**When** 使用带自环的 RC smoothing matrix `P` 生成 pseudo-cell
**Then** 行归一性必须成立：

```math
\sum_j P_{ij}=1
```

且：

```math
P_{ii}=1-g_i
```

```math
P_{ij}=g_i a_{ij}
```

### 这个实验代表什么

```text
analytic_RC 验证完整 reliability-controlled local shrinkage 是否成立。
```

### 成功标准

```text
analytic_RC 比 fixed 更少负迁移；
analytic_RC 不丢失所有 positive gains；
analytic_RC 优于 random_delta_matched；
edge_only 或 gate_only 至少一个有独立贡献；
gate 与 edge diagnostics 不 collapse；
graph TV 不显示明显过平滑。
```

# 4. Stage 1 的 pseudo branch 训练目标

## Feature 6：pseudo reconstruction-only

### 背景

pseudo-cell 是合成视图，不是真实细胞。
如果 pseudo branch 完整复制 scMAE loss，可能让模型学习合成痕迹。

### 主线 loss

real branch 保持原始 scMAE：

```math
L_{real}
=
L_{rec}(\operatorname{Mask}(x_i),x_i)
+
\lambda_{mask}L_{BCE}(\hat{m}_i,m_i)
```

pseudo branch 只做 anchor reconstruction：

```math
L_{pseudo}
=
L_{rec}(\operatorname{Mask}(\tilde{x}_i),x_i)
```

总损失：

```math
L
=
L_{real}
+
\lambda_{pseudo}L_{pseudo}
```

### Scenario 6.1：pseudo rec-only

**Given** pseudo-cell `\tilde{x}_i` 来自 RC smoothing
**When** 输入 pseudo branch
**Then** pseudo branch 只重构 anchor cell `x_i`，不计算 pseudo mask BCE。

### 本轮是否要做 full_pseudo 消融？

不是第一优先级。

只有在以下情况发生时才做：

```text
analytic_RC 有效，但审稿叙事需要解释 pseudo branch；
或 rec-only 与 fixed 差异不稳定；
或旧结果显示 pseudo mask BCE 可能影响很大。
```

可选消融：

```text
analytic_RC_rec_only
analytic_RC_full_pseudo
```

不作为第一批必跑。

# 5. Stage 1 负对照：random_delta_matched

## Feature 7：排除普通扰动解释

### 背景

如果 RC-NM 有效，必须证明它不是因为“随便加点扰动也有效”。

### 核心指标

```math
\Delta_i
=
\|\tilde{x}_i-x_i\|
```

其中：

```text
Δ_i：
  perturbation norm，扰动范数。
```

### Scenario 7.1：random_delta_matched

**Given** analytic_RC 产生每个细胞的 perturbation norm
**When** 构造 RandomMix pseudo-cell
**Then** RandomMix 的 perturbation norm 分布应与 analytic_RC 尽量匹配。

随机扰动形式可以是：

```math
\tilde{x}_i^{rand}
=
(1-\eta_i)x_i
+
\eta_i x_{r(i)}
```

其中 `r(i)` 是随机细胞，`η_i` 用于匹配扰动强度。

### 这个实验代表什么

```text
random_delta_matched 验证“可靠邻域”是否真的比普通扰动重要。
```

### 成功标准

```text
analytic_RC 明显优于 random_delta_matched；
尤其是在 negative datasets 上减少 fixed 负迁移。
```

### 失败解释

```text
analytic_RC ≈ random_delta_matched：
  不能声称可靠邻域是主要机制。
  主张应降级为 perturbation regularization。

random_delta_matched > analytic_RC：
  当前可靠性定义可能错误，或邻域混合本身不适合该数据。
```

### 9.4 graph total variation diagnostics

本轮不训练 gene gate，但要做 graph TV 诊断。

对每个基因：

```math
TV_g(X)
=
\sum_{i,j}A_{ij}(x_{ig}-x_{jg})^2
```

比较：

```math
TV_g(X)
\quad vs \quad
TV_g(\tilde{X})
```

保存：

```text

HVG_TV_ratio
```

其中：


# 13. 是否做 AE 迁移：只作为 Stage 1 通过后的最小检查

## Feature 15：scMAE-first，但不是 scMAE-only

### 背景

当前交流中已经明确：scMAE 不应作为方法身份边界。
但现在也不应立刻换题。

### 进入条件

只有当 Stage 1 达到 A 档或接近 A 档时，才做最小非 MAE 检查。

### 最小 AE 迁移

只做：

```text
AE_noMix
AE_fixed
AE_RC
AE_random_delta_matched
```

不做：

```text
scVI 内部重写
scGPT fine-tuning
scFoundation adaptation
GNN backbone
large-scale transformer
```

### 目的

回答：

```text
RC-NM 是否只是 scMAE-specific trick？
还是可以作为 backbone-agnostic local shrinkage regularizer？
```

### 结果解释

```text
AE_RC 也有效：
  主张升级为 backbone-agnostic regularizer。

AE_RC 无效，但 scMAE 有效：
  主张收窄为 masked autoencoder-specific pseudo-cell regularizer。

AE_RC ≈ AE_random_delta_matched：
  可靠邻域机制仍然不足。
```

# 14. 暂缓项及进入门槛

## Feature 16：不把扩展模块塞进第一轮

### 14.1 attention 暂缓

不做：

```text
full graph attention
GAT
Transformer
attention-only RC
```

只有当 analytic_RC 有效但边权表达能力不足时，才考虑：

```math
a_{ij}
=
(1-\rho_i)\bar{r}_{ij}
+
\rho_i b_{ij}
```

并限制：

```math
\rho_i \le 0.3
```

即 attention 只能作为 residual correction，残差修正器。

---

### 14.2 gene gate 暂缓

本轮只做 graph TV diagnostics，不训练 gene gate。

进入 gene gate 的条件：

```text
graph TV 显示高 TV genes 被过度压缩；
rare-cell recall 下降；
per-cell-type F1 下降；
边界细胞明显被抹平。
```

---

### 14.3 perturbation budget 暂缓

扰动预算正则：

```math
L_{budget}
=
\left(
\frac{1}{B}\sum_i \|\tilde{x}_i-x_i\|
-
\Delta_0
\right)^2
```

不进入第一版主模型。

只有出现：

```text
gate 大量接近 0；
扰动强度极不稳定；
RC 与 random_delta_matched 难以公平比较；
```

才加入作为稳定项。

---

### 14.4 NB/ZINB 暂缓

不做 count-aware reconstruction。

原因：

```text
NB/ZINB 改的是 reconstruction likelihood；
RC-NM 改的是 neighborhood smoothing bias；
两者现在混在一起会污染机制判断。
```

# 17. 最终执行结论

下一步不要做完整论文工程。
也不要现在把方法扩展到 attention、gene gate、NB/ZINB。

最小可行性 BDD 就是：

```text
1. 把方法重写为带自环的 reliability-controlled smoothing operator；
2. 实现 edge reliability + edge veto；
3. 实现 benefit-risk cell gate；
4. pseudo branch 只做 anchor reconstruction；
5. 跑 fixed / edge_only / gate_only / analytic_RC / random_delta_matched；
6. 用 gate、edge、perturb_norm、graph TV 诊断机制；
7. 根据结果决定继续、收窄主张或止损；
8. 只有 Stage 1 通过后，再做 AE minimal transfer，判断是否 scMAE-only。
```

这才是当前最合适的 BDD：**足够完整，可以指导实现和判断；但没有铺成全面验证工程。**
