## 一句话

> **《带正确性保证的 GPU 加速单细胞聚类》**：把单细胞聚类从 CPU 迁到 GPU(cuML)，
> 用一个**结构感知、噪声带校准的统计等价正确性协议**证明"加速没有算丢稀有细胞类型"，
> 并以 DEC+std-floor 为旗舰案例。

## 论文的三个 claim（就这三个，不多）

1. **动机（已基本完成，Phase 1）**：深度单细胞方法朴素 `.to(cuda)` ≈ 零收益(小模型
   GPU 训练不比 CPU 快、利用率 5%)；真瓶颈是 CPU 经典步骤(PCA/KNN/KMeans)——超线性、
   200k 整管线 CPU 不可行；cuML 迁移拿到 PCA 7–15× / KMeans 20–33× / KNN 7–28×，
   规模越大越值。
2. **核心贡献（脊梁，待做 = M2）**：**结构感知统计等价正确性协议**。GPU 迁移用近似算子，
   可能悄悄退化稀有/细粒度结构而聚合 ARI 看不见 ⟹ 正确性判据必须分层(整体 ARI/NMI +
   稀有簇 recall + 每簇 F1 + 方差谱/eff-dim)，且落在**多种子噪声带**内(如 Macosko
   0.576±0.087)才算"迁移正确"。区别于 KernelBench(bit-match)、Correctness-Illusion(数值级)。
3. **旗舰案例（待做）**：DEC+std-floor 迁到 GPU 后，方差地板救援(eff-dim 60→114)是否
   保留？稀有亚型是否守住？
