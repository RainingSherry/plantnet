## 1. 阶段一：继续攻 scMAE 聚类精度（大量消融，结论=证否）

问题：能否在 scMAE(masked autoencoder) + DEC + 每维方差地板(std-floor) 这个已知
最强骨干上，再提升细粒度/植物单细胞聚类精度。

做过的消融（都带同管线对照、多种子）：
- **Gene-program bottleneck**（`experiment_reports/program_bottleneck_ablation_20260703/`）：
  把 NMF 基因程序当辅助正则。结果：真 program 反而比"随机置换的假 target"伤得更重
  → 表达派生的伪结构主动把 embedding 拉向非细胞类型轴。**证否。**
- **Decoder-bypass**（`experiment_reports/decoder_bypass_ablation_20260703/`）：测 scMAE
  decoder 的 mask 旁路是不是结构捷径。结论：它是**稳定器**不是捷径；去掉在 Melanoma
  平均 +0.067，但 Macosko 剧烈双峰(lowrank seed43=0.872 但多数种子崩)。
- **Phase-1b**：追那个 0.872。各 mask_rank 命中 0.8+ 仅 12–25%，**不可靠**。
- **Conditional / nuisance-matched shuffle**（`experiment_reports/conditional_shuffle_ablation_20260703/`）：
  把 scMAE 的 swap-noise 供体限制在同 nuisance 箱。**Macosko +0.16 稳定(0.867)且双头
  验证**，但**完全不泛化**(Melanoma/Quake 持平)，机制假设(nuisance≈type)被 NMI 检验证否；
  **植物数据(SRP182008/CRA002977)也不迁移甚至变差**。Macosko 独特原因未知。

一个跑偏后自我纠正的诊断（Phase-0 gate，`experiment_reports/clustering_head_reeval_20260703/`）：
换聚类头(KMeans/GMM/Leiden)重评冻结 embedding，**证明瓶颈是 embedding 不是聚类头**
(在真实粒度 k≈12 时 KMeans-known-K 最好；Leiden 的高分是粗划分+类不平衡假象)；同时
发现"silhouette 选分辨率"在不平衡数据上是坏的 label-free 选择器。

**阶段一净结论**：DEC + 每维 std-floor 仍是稳健跨数据集赢家；所有外挂/结构机制在这个
家族里都不能通用地超过它。"改进精度"这条线基本走到头——这成为转选题的依据。

## 4. 已完成的两步实证

### Phase 1 — CPU↔GPU 缺口实测（`experiment_reports/phase1_gpu_gap_20260703/`）
硬件 8×H100/192核/2TB。分阶段计时旗舰 scMAE+DEC+std-floor：
- **经典步骤(PCA+KNN) CPU 超线性爆炸**：neighbor 2.9s(10k)→56s(50k)→161s(86k)，整条
  CPU 管线 **200k 直接超时不可行**，经典占比升到 95%。
- **反直觉核心**：小模型 GPU 训练不比 CPU 快(train/ep 0.29 vs 0.27)、GPU 利用率仅 5%
  → **朴素 `.to(cuda)` ≈ 零收益**。真瓶颈是 CPU 经典步骤 + 饿死 GPU 的数据管线。
- 新建 `rapids_bench` 环境(RAPIDS 25.04/cuML)，实测 **cuML vs sklearn：PCA 7–15× /
  KMeans 20–33× / KNN 7–28×，规模越大越值**。
- 立意升级：从"GPU 更快"(弱) → "**朴素迁移零收益，必须智能分阶段迁移 + 守正确性**"(强)。

### M2 — 结构感知正确性协议第一步（`experiment_reports/m2_correctness_protocol_20260703/`）
sklearn(CPU) vs cuML(GPU) KMeans，旗舰 3 训练种子 embedding × 3 KMeans 种子，分层指标：

| 指标 | CPU | cuML | Δ | 判定(band ±0.087) |
|---|---|---|---|---|
| ARI | 0.7014 | 0.7206 | +0.019 | 等价 |
| NMI | 0.6535 | 0.6605 | +0.007 | 等价 |
| macro-F1 | 0.4151 | 0.4153 | +0.0002 | 等价 |
| 稀有簇 recall | 0.4355 | 0.4355 | +0.0000 | 等价 |

KMeans 加速 ~20×。**结论=协议价值的活证据**：稀有簇/每簇 F1 几乎完全一致 → 你诊断的
脆弱结构在 GPU 迁移后完好；差异只在聚合(cuML 还略高)。方法学要点：等价带必须用方法
自身重训波动(±0.087)，不是 frozen embedding 的近确定性带；cuML 默认 n_init=1≠sklearn
的坑必须先对齐。

（诚实记录：过程中我一度误报"cuML 让 ARI 掉到 0.593"——那来自一次语法错误挂掉的运行，
是错的；干净重跑后真相相反，已改正。）
